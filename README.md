# 猫咪在哪里

一款无需安装、无需联网的浏览器逻辑游戏，参考手机截图的彩色区域找猫玩法，针对电脑和手机重新排版。

## 开始游戏

双击本目录的 **index.html**，用 Edge、Chrome、Firefox 或 Safari 打开即可。所有图片、样式、脚本和关卡均为本地资源，不需要服务器或网络。

电脑推荐直接打开本地文件。手机可以使用支持本地 HTML 的浏览器／文件工具，也可以将整个目录通过静态服务器提供给手机浏览器。手机系统的文件预览器可能不执行网页脚本。

## 规则与操作

- 每行、每列、每个颜色区域恰好有一只猫。
- 猫咪不能相邻，包括斜角。
- 电脑左键单击排除，左键双击或右键单击放猫；按住左键拖过多个格子可连续排除。手机点击排除，双击放猫，按住滑过多个格子可连续排除。再次操作可取消已有标记或猫咪。
- 只有找对答案的位置才会显示猫头；点错会显示醒目的红色 × 并消耗一次机会。
- 自动排除始终开启：找到猫咪后，与它同行、同列、同色块或相邻的格子会自动显示白色粗叉；移走猫咪后自动恢复。自动标记只反映当前摆放，不代表当前摆放一定是最终答案。
- 违反规则会消耗一次机会，每关 3 次。机会用完可以重新挑战。
- 撤销可还原最近 100 步，但不会恢复已消耗的机会。
- 提示先高亮并说明原因，再次点击才应用。提示不限次数。遇到不直接冲突但会造成无解的猫咪，提示会帮助移走。
- 快捷键：C 放猫、X 排除、方向键移动、空格／回车操作、Ctrl+Z（Mac 为 Cmd+Z）撤销、P 暂停。
- 排除操作会播放轻快点击音，拖动或滑动连续排除时每经过一个新格子都会立即响一次；正确找到猫咪会播放 `cute-kittens.mp3` 猫叫声，错误音效保持低沉提醒。
- 胜利和失败结算页都会循环播放 `哈基米战歌.mp3`，关闭结算页或进入新棋盘后停止。
- 主界面的「快速设置」直接提供色盲字母标识和行列坐标；音效与自动排除始终开启。

## 关卡与存档

轻松 5×5、进阶 7×7、挑战 10×10，三个难度都会无限随机生成。每次刷新页面、点击重来或进入下一关都会使用新的随机种子，因此分享给不同玩家时，每个人拿到的棋盘也会不同。每个棋盘的区域连通并且只有一个解；挑战关每个色块至少包含 4 格，并限制最大面积，减少直接暴露答案的简单线索。

游戏不会保存正在进行的棋盘，所以刷新后一定会换题。当前难度、累计完成数、当前连胜、历史最高连胜、色盲辅助和坐标设置会保存在当前浏览器中。更换浏览器、移动文件路径、清理浏览器数据或使用无痕窗口，可能无法读取这些记录；浏览器禁用存储时游戏仍可正常进行。

计时从第一次操作开始；切换到后台、打开弹窗或手动暂停时停止计时。

## 项目结构

- `index.html`：网页及内嵌 SVG 插画。
- `styles.css`：桌面／手机布局及动画。
- `app.js`：随机开局、游戏交互、提示、音效、设置和记录。
- `engine.js`：独立求解器、规则判断与棋盘变换。
- `levels.js`：供测试与生成工具使用的验证样本；实际游玩直接生成随机棋盘。
- `assets/audio/cute-kittens.mp3`：正确找到猫咪时的猫叫声。
- `assets/audio/哈基米战歌.mp3`：胜负结算页背景音乐。
- `tools/generate-levels.cjs`：可复现的关卡生成工具。
- `tests/engine.test.cjs`：关卡唯一性、连通性及规则测试。

无需安装依赖即可运行游戏。开发检查使用 Node.js：`node --test tests/engine.test.cjs`。重新生成关卡：`node tools/generate-levels.cjs`。
